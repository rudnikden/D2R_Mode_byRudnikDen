# D2R_Mode_byRudnikDen

All-in-one **offline** mod for Diablo II: Resurrected (3.x, Reign of the Warlock), made for [D2RMM](https://www.nexusmods.com/diablo2resurrected/mods/169).

**Everything is OFF by default**: with default settings the game is unchanged.
Settings are available in **English, Українська, Русский** (the *Language* field at the top). Every field has a tooltip with its default, its maximum and what they give.

## Sections

1. **Class loot filter**: class-only items of other classes stop dropping. Items any class can use still drop.
2. **Item quality (all drops)**: chances for unique, set, rare, magic and superior items. Presets: *Runeword bases*, *Balanced*, *Unique hunting*, *Custom*.
3. **Specific item hunt**: pick up to 6 items by name with a chance per monster: unique and set items (each Rainbow Facet variant too) and white runeword bases. Unique and set items drop where monsters are high enough for them; runeword bases drop on every difficulty from any monster, even elite ones.
4. **Good drops: runes, jewelry, gems**: how often good drops happen, how many of them are runes, how high the runes are, and room for the Countess's 3 runes.
5. **Horadric Cube recipes**: 1 gem → 2 gems one quality lower; 1 rune → 2 runes one level lower; 1 healing + 1 mana potion → Full Rejuvenation; Hel + skull + unique item → 1 socket, like Larzuk's reward; Ral + Amn + Thul + weapon, armor, shield or helm → item with the chosen number of sockets (ethereal and superior are kept).
6. **Pandemonium keys and essences**: key drop chance ×1–100; every Hell act boss always drops its essence for the Token of Absolution.
7. **Easier Uber bosses: Diablo Clone, Izual, Duriel, Lilith**: levels *Slightly easier*, *Medium*, *Super easy* or *Manual*. Ordinary Andariel, Duriel, Izual and Diablo stay the same.
8. **Easier Uber Tristram**: the same levels for Uber Mephisto, Uber Diablo and Uber Baal. The number of their minions is set in the game code and cannot be changed.
9. **Best charms: Annihilus and Hellfire Torch**: random as in the normal game, the best values or your own numbers; the Torch class can be chosen. Only a newly dropped charm gets them.
10. **About the author**: feedback email and a developer code that unlocks a secret item.

## Install

1. Double-click **Install.cmd** from the zip: it finds D2RMM and puts the mod into its `mods` folder. Or copy the `D2R_Mode_byRudnikDen` folder into `D2RMM/mods` yourself.
2. Start D2RMM, enable the mod and change the settings you want.
3. Press **INSTALL MODS**, then **RUN D2R**. Repeat INSTALL MODS after every settings change.

**Back up your saves first.** Modded games use their own save folder (`Saved Games/Diablo II Resurrected/mods/<mod name>`). Offline only.

## Playing without the mod

Items found or made with this mod are ordinary game items, so the character loads without it. To move a character back: put all items inside the original inventory area, close the game, back up both save folders, copy the character files from `Saved Games/Diablo II Resurrected/mods/D2RMM` to `Saved Games/Diablo II Resurrected`, start the game without mods.

Works with [Expanded Inventory](https://www.nexusmods.com/diablo2resurrected/mods/172) by olegbl, a separate mod. Before playing that character without it, move every item into the original 10×4 inventory area.

Notes: item names come from the game's own localization; the game has no Ukrainian locale, so the Ukrainian version shows English item names. The mod edits both table sets of D2R 3.x (`global/excel` and `global/excel/base`).

## Українською

Мод для **офлайн**-гри через D2RMM. **Усе вимкнено за замовчуванням.** Мова налаштувань: поле *Language* угорі.

Розділи: 1. фільтр луту за класом; 2. якість предметів із пресетами; 3. полювання на конкретні речі за назвою; 4. хороший дроп: руни, коштовності, камені й місце під 3 руни Графині; 5. рецепти куба: зниження каменів і рун, просте повне омолодження, гніздо в унікальну річ, кузня гнізд; 6. ключі Пандемоніуму й гарантовані есенції для Token of Absolution; 7. легші Uber-боси: клон Діабло, Ізуаль, Дуріель, Ліліт; 8. легший Uber Tristram; 9. найкращі Annihilus і Hellfire Torch; 10. про автора та код розробника.

Після кожної зміни: **INSTALL MODS**, потім **RUN D2R**. Зробіть резервну копію збережень. Назв предметів українською в грі немає, тому вони англійською.
